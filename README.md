# Rock Paper Scissors Game 

Jogo clássico Pedra, Papel e Tesoura feito em **HTML, CSS e JavaScript**.

## Como jogar
- Clique em **Play vs Computer** para jogar contra a CPU.
- Clique em **Play vs Player 2** para jogar contra outro jogador.
- Escolha entre Pedra, Papel ou Tesoura e veja o resultado na tela.

## Tecnologias usadas
- HTML5
- CSS3 (com gradiente animado estilo PS5)
- JavaScript

## Como rodar
Basta abrir o arquivo `index.html` no navegador.
